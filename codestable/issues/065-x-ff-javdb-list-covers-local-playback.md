# 清单展示全部影片封面并标记本库 STRM 可播放状态

按用户澄清，关联清单显示全部 JavDB 影片的标题、番号和封面，未匹配本库的影片继续保留。封面右上角显示“本地可播放”或“无本地 STRM”；封面、标题进入 JavDB 详情，实际可播放条目另有本库详情入口。当前局部布局见 [功能说明](../../docs/JAVDB-COMMUNITY.md)。

- 改动：`internal/server/javdb_community.go` 返回清单影片与附属本库版本；`r18_local.go` 将当前库范围接入已有 STRM 校验并保留原跨库包装入口；社区 API、组件及两个回归文件，主说明和 R18 说明。
- 边界：每次读取一页 50 条，通过一次单库 SQL 查询匹配当前影片所属库并核验实际 STRM。可读库内文件与合法 HTTP/HTTPS 地址才标记可播放；不探测视频源。分页按 JavDB ID 去重，多个本库版本保留，分段按本地影片 ID 去重；图片复用同源代理、海报缓存和隐藏设置。权限、清单关联及请求身份核验继续执行。
- 验证：R18 社区、Store 与原本地播放定向回归、Go vet、Vue 类型检查、532 项前端单测及最后文案调整后的 18 项回归、11 项构建检查、Vue/embedui 构建通过。隔离浏览器覆盖全量与未匹配清单、封面及占位、角标、续页去重、失败保留重试、迟到及库身份、隐藏图片、JavDB/本库详情返回；1280/390/320 像素浅深色六组布局通过，截图已检查。375 像素手机、844×390 横屏、28 像素放大文字及减少动态效果模式通过。
- codestable：无现有 Project/Epic Spec 需同步；更新功能说明及 [原本库匹配记录](064-x-ff-javdb-list-local-matches.md) 的后续链接。用户已授权提交推送，交付记录见 Git 历史；真实 AVdb 待用户实测，未部署。
