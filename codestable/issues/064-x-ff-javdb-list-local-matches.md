# 关联清单只匹配当前媒体库影片

按用户补充要求，关联清单点开后读取清单影片番号，批量匹配当前详情影片所属媒体库的可见条目；没有对应番号的直接跳过。条目展示本库标题并进入本库详情，清单入口改为“查看本库影片”。

- 改动：`internal/r18/community.go` 清单影片分页、`internal/server/javdb_community.go` 关联核验及本库结果；`internal/store/r18_local.go` 增加显式单库范围并复用原批量番号查询，原 R18 跨库 STRM 查询不变；社区 API/组件、普通详情入口、四个回归文件和功能说明。
- 边界：范围只取当前影片的 `library_id`，其他可访问库不参与；使用原完整番号规则、可见影片状态和非剧集范围，不读文件或猜测番号。每次最多读取四个上游页、一次单库 SQL 查询，后续可继续，未匹配批次不冒充清单结束；本库索引不缓存，累计条目按本地 ID 去重。清单需证明关联当前 JavDB 影片，源站失败不当作未匹配，数据身份与取消规则继续生效。
- 验证：R18/服务器/Store 定向回归、完整 R18 包、Go vet、前端 531 项单测及类型检查、11 项构建检查、Vue/embedui 构建通过。隔离浏览器的本库点击与详情返回、空态、续页去重、失败重试、库身份变化及迟到响应通过；1280/390/320 像素浅深色六组布局和触控尺寸检查通过，截图已检查。
- codestable：无现有 Project/Epic Spec 需同步；当前操作和接口在 `docs/JAVDB-COMMUNITY.md`，接续 [首次接入记录](063-x-ff-javdb-detail-community.md)。用户已授权提交推送，交付记录见 Git 历史；真实 AVdb 实例待用户实测，未部署。
