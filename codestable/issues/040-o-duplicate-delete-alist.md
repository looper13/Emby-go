- 目标：管理员展开重复番号分组后，可对指定副本预览主文件/CD 分段的本地与远程路径，勾选确认后通过 AList 删除远程原文件，再清理本地 STRM 和索引。
- 实现已完成：查重成员新增“删除此副本”及原生模态确认窗口；设置页新增 AList 地址与 API Token，持久化后即时生效，Token 只返回配置状态、空输入保留、显式清除。只解析同配置服务地址的 `/d/`、`/p/`、`/dav/` 文件路径，支持签名 URL、中文/空格/特殊字符和反向代理子路径；供应商直链拒绝定位。
- 后端新增管理员预览/删除接口和独立 AList 客户端：按文件路径调用 `fs/get` 获取当前副本的文件信息，使用 `fs/remove` 的单文件 `dir/names`；不访问 STRM 播放 URL、不跟随管理 API 重定向、不转发 Emby 凭据、不回显 AList 错误中的秘密。预览签名有效 10 分钟，确认时核验当前影片、STRM 摘要和 AList 返回的远程文件 ID/大小/修改时间。
- 2026-10-24 用户确认片源独立，不需要共享引用保护，已移除全库 STRM 读取与共享引用检查，也不读取保留副本；不再调用 `fs/list` 分页遍历目录。媒体库目录范围、普通 STRM、符号链接边界和最多 64 分段检查保留。与扫库/刮削/探测/编辑及其他删除共用写入通道，配置保存期间立即返回冲突提示，预览整体超时 60 秒、页面等待最多 65 秒。修正记录见 `041-x-ff-duplicate-delete-preview.md`。
- 远程删除进度持久化到 SQLite `movie_deletions`（影片删除时级联清理）。分段失败保留全部本地 STRM 和索引，重新预览可继续；网络响应丢失但远程实际已删除也可重新核验后继续。清理本地时逐文件复核摘要，不递归删除目录；NFO、封面和其他文件保留。跨网盘/本地删除无法事务回滚，失败窗口会显示已删除路径。
- 初版验证（共享引用保护已按用户要求撤销）：AList/config/store 全套及 server 的删除、配置、账号/用户、媒体库监听与缓存相关测试通过；涵盖主流程、权限、任务互斥、共享引用、预览后变化、部分失败、重启恢复、响应丢失、Token 脱敏、路径编码/穿越和管理请求拒绝跳转。完整前端 29 文件 299 项、类型检查、构建通过，Go vet 与 embedui 构建通过。修正后的验证见 041。
- 浏览器：独立临时配置/数据库/Redis/媒体目录和本地 AList HTTP fixture；Chrome 1280×900 与 390×844 均显示原生模态框、确认前禁用删除、无横向溢出/脚本错误。桌面 Esc 取消零删除，窄屏完成远程删除、本地 STRM 消失、索引/查重统计更新，保留副本与 NFO 存在。脱敏截图在忽略目录 `.work-cache/duplicate-delete-qa/`。
