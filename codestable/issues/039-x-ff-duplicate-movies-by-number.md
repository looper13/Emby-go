- 媒体库页新增“影片查重”面板及每库快捷入口；管理员可查全部库的跨库重复或限定单库。仅使用已入库番号，忽略 ASCII 大小写、空格/制表符/换行、连字符、下划线和点，保留数字前导零及版本后缀。空番号和电视节目排除；CD 分段沿用单个索引条目，有番号的未就绪影片参与。只读查询，不删文件或索引。
- 已实现的局部界面：
  ```text
  媒体库列表：名称 / 路径 / … / [查重]
  影片查重：[全部媒体库或单库 v] [开始查重]
  说明：按当前索引查重；磁盘变更先增量扫描
  汇总：重复组数 / 涉及影片数 / 多出副本数
  番号 / 份数 / [查看位置或收起]
    影片详情链接 / 状态 / 媒体库 / 原始番号 / 主文件与分段路径
    [组内影片分页]
  [重复番号分组分页]
  ```
- 初始不查询，点击才统计；展开时再取成员。两层独立分页；切换范围会取消旧读并清除旧范围结果，晚到响应不能覆盖当前结果。错误可重试；没有结果时显示“未发现重复影片”。窄屏控件换行，路径可断行；只引入局部样式，冻结的 `legacy.css` 未改。
- 改动：新增 `internal/store/duplicates.go` 的 SQL 聚合/成员查询与测试、服务端 `/api/admin/duplicates` 和 `/duplicates/items` 管理员接口及权限/参数测试；Vue 查重 API/面板/单测、媒体库页入口、`library.css` 与 README。统计及当页数据使用同一只读事务；数据库聚合并分页，不将全部影片元数据加载进 Go 内存。
- 验证：Go 查重存储/HTTP 集成与账号库授权回归通过；完整前端单测 29 文件、295 项通过，类型检查与前端生产构建通过，`embedui` 后端构建通过。存储回归覆盖跨库/单库、格式归一化、边界番号不误并、空番号、电视节目、CD、双层分页、用户访问范围、取消与索引变化立即可见；前端覆盖按需查询、范围切换取消/拒绝旧结果、展开/收起、失败重试和成员翻页。
- 浏览器：使用独立临时数据库、配置、媒体目录的真实服务，验证全部库跨库查重、ALDN-001/aldn001/ALDN_001 归组、展开主文件路径、切换单库后的正确统计；桌面展开态截图已检查。没有扫描现有生产媒体库；未进行百万条数据或手机浏览器实测，未部署。
