- 已实现：当前媒体库范围内，每个重复番号保留最早/最新加入、路径最短/最长的一份，其他副本全量跨页选中；成员可取消个别勾选，翻页保留选择，切换范围/规则清空。首次入库时间来自 `created_at`，完整主路径按字符数；未知时间后置，同值用较小 ID 确定保留副本。用户确认本轮改动并授权提交推送；真实网盘验收边界见下。
- 当前局部界面：
  ```text
  [媒体库范围] [开始查重]
  [每组保留规则] [全量选择多余副本] [批量删除 N 份] [清空选择]
  番号组 -> 查看位置 -> [待删勾选] 或 [按规则保留]
  批量确认窗口：范围 / 规则 / 全量份数 / 已完成进度
    待删主/CD 路径 / 加入时间 / 字符数
    对应保留路径 / 加入时间 / 字符数
    [上一页/下一页清单] [确认勾选] [确认批量删除]
  执行中：[停止队列]；失败/停止：[重新勾选确认并继续]
  ```
- 改动：`store/duplicate_selection.go` 用单个 SQL 窗口查询快照选择全部多余副本，沿用番号归一化、电视/空番号排除、库权限/CD 单部语义；不依赖展示分页，不读取文件。管理员 `/api/admin/duplicates/selection` 返回目标/保留元数据与选择签名。现有单份预览/删除可携带 `keep_id`、`selection_token`，核验当前目标与固定保留副本的索引/路径/分段/入库时间/库目录；保留副本丢失或快照变化即拒绝，包含部分删除恢复场景。原单份接口调用不变。
- 前端 `DuplicateBulkDeleteDialog.vue` 在全量清单确认后串行逐份获取新预览再删除；不预先保存容易过期的删除签名。首个失败停止，报告已成功份数与当前项已删除的远程路径；停止预览可取消，正在删除则完成当前项后停下。关闭/导航不会开始下一项，队列不后台持久化；页面重开应重新查重/选择，单份删除进度沿用现有 SQLite 状态。远程对象按执行时 STRM 和 AList 返回元数据核验，不声称跨网盘/本地事务或外部并发文件强一致性。
- 验证：store/AList 全套、server 查重/选择/删除/STRM/媒体库权限定向测试与 Go vet 通过；覆盖四种规则/同值/未知时间、Unicode 路径长度、31 组跨库全量、单库/权限、空番号/电视/单份排除、无远程请求的选择、固定保留份、快照变化、部分删除后保留份丢失拒绝继续。前端 30 文件 314 项、类型检查、生产及 embedui 构建通过，覆盖跨页选择/取消个别勾选、旧请求取消、确认/串行/防重复、停止/离开、部分失败与重新确认、完成刷新。
- 浏览器：独立临时配置/数据库/Redis/媒体目录及本地 AList `fs/get`/`fs/remove` fixture，Chrome 1280x900 和 390x844 原生模态、清单/整页无横向溢出、确认前按钮禁用；Esc 取消零 AList 请求。页面展示 20 组时选中全量 31 组，窄屏确认删除 31 个逻辑副本（含 CD 共 32 个远程文件），31 个保留 STRM、62 个 NFO 完整，查重归零；没有查询保留远程文件、没有浏览器脚本错误。截图在忽略目录 `output/playwright/duplicate-bulk-*.png`。
