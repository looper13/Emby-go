# R18 封面与剧照统一走服务器图片代理

按用户要求，将 R18 列表/详情封面、首末剧照及查看原图链接改为同源服务器代理。源图 URL 不再下发为图片地址，代理只接受已授权条目与图片序号；播放及磁力展示边界不变。实现与本地验证完成，用户已授权提交推送；未部署。

- 改动：`internal/server/r18_images.go` 的图片响应与既有缓存/限流，`internal/r18/images.go` 的公网目标校验/重定向/DNS 固定/独立请求；`internal/server/r18.go` 改写展示 URL，`frontend/src/api/r18.ts` 仅接受同源图片代理路径。
- 护栏：缓存/304 前校验媒体库授权；不转发用户 Cookie/Token，拒绝私网等目标及 HTML/SVG；4 路上游并发、15 秒 HTTP 超时、8 MiB 上限，小图复用 10 分钟内存缓存，私有 ETag 重验证。
- 验证：R18 代理鉴权/授权撤销/缓存/HEAD/304/原始 MIME/超限/失败重试与网络目标校验测试通过；图片、账号、媒体库、目录与剧集相关后端回归通过。前端类型检查、35 文件/351 单元测试及 Vue/embedui 构建通过。
- 实库/浏览器：隔离实例只读接入真实来源，列表 40 条中当前可视区 25 张封面成功加载；详情封面及两张剧照加载成功，原图代理 200/304。浏览器没有跨源图片请求；390 像素无横向溢出，隐藏图片后无封面/剧照 img，3 条磁力仍正常。
- codestable：无现有 spec；同步 `R18-CATALOG.md`。本机直连图片站被重置，隔离预览通过本机已配置的出网代理验收；正式服务器须可访问源图站，可使用进程环境 `HTTP_PROXY`/`HTTPS_PROXY`，无需开启播放代理。
