- 问题/根因：用户遇到 AList 文件不存在后整批阻塞；浏览器队列的异常分支直接 `break`，且进度游标同时充当成功数，不能只改为跳过而不区分结果。
- 已修复：按副本保存成功/失败、错误及部分远程删除路径；单份预览或删除失败后继续后续副本，失败不算成功。每轮快照每份只尝试一次，失败不自动循环重试；停止后先确认继续未处理项，全部处理后确认仅重试失败项，成功项不重复执行。支持分页筛选失败清单，切换筛选或清单页回到顶部。关闭回传真实成功数刷新统计。
- 局部状态（原异常直接停止；当前目标及实现如下）：
  ```text
  执行中：已处理 N / T（成功 S，失败 F），未处理 U
    单份失败 -> 记录原因/已删除远程路径 -> 下一份
    [停止队列] -> 当前已发出删除完成后停，不启动下一份
  本轮结束：[只看失败 F 份] -> 分页显示失败/待删/保留路径
    [重新勾选确认] [仅重试失败 F 份]
  ```
- 范围/边界：只改 `DuplicateBulkDeleteDialog.vue`、相关测试和文档；沿用现有选择签名、固定保留副本、单份 AList 预览/删除及 SQLite 部分删除恢复，不放宽远程不存在、路径变化或权限核验。停止/导航取消预览，不把取消计为失败；已发出的删除仍完成服务端清理记账。失败清单是页面内状态，不后台持久化。
- 验证：前端 30 文件 320 项、类型检查、生产及 embedui 构建通过；相关 15 项涵盖真实错误格式/409、缺失后继续、部分删除路径隔离、仅失败重试、不自动循环、全失败、停止/导航、失败筛选分页/滚动及成功数刷新。server 查重/选择/删除/STRM 定向回归通过。
- 浏览器：独立临时配置/数据库/Redis/媒体目录及本地 AList fixture，31 份中的第一份和中间一份明确不存在；仍处理完全部 31 份，成功 29、失败 2，失败的 3 个 STRM、31 个保留 STRM、62 个 NFO 完整。恢复两个远程对象后只重试失败项，成功 31、失败 0，累计远程删除 32 个（含 CD），查重归零；关闭后统计刷新。1280x900/390x844 原生模态及失败筛选无横向溢出；浏览器仅有预期的两次缺失文件 HTTP 409，无脚本异常。截图在忽略目录 `output/playwright/duplicate-bulk-failures-*.png`。
