媒体墙排序菜单新增「首映日期」「随机」。首映日期使用已有 NFO premiered 索引，默认最新在前，空日期放最后、同日按 ID 稳定排序。随机模式按本次浏览生成固定种子，翻页、详情返回和过期快照重载保持顺序；「换一批」生成新种子并回到首屏。切换筛选或整页刷新可产生新顺序。

- 改动：`WallFilters.vue`、`MediaWallPage.vue`、`stores/media-wall.ts` 增加菜单/换一批与种子生命周期；`admin.go` 解析 31 位种子并纳入响应缓存键；store 排序参数改为私有结构体，媒体墙在 SQL 中按种子生成稳定打乱顺序，保留原有筛选、计数与 LIMIT/OFFSET。动漫投影仅适配私有参数形状，兼容客户端的既有 Random 占位行为保持原样。无需数据库迁移。
- 验证：类型检查、62 项媒体墙/媒体交互单测、store 全套、CoreAPI/Vue 契约/缓存隔离定向服务端测试、新增 HTTP 种子与缓存测试均通过。测试覆盖随机 215 条全量与分页面一致、跨种子隔离、非法种子归一化、首映日期正反序和缺失日期位置。生产 UI 构建与 Windows embedui 编译通过。
- 浏览器：真实 Chrome + 隔离 Go/Redis 夹具库，首映日期降序；随机连续三页 300 条且 300 个唯一 ID，三页同种子；详情往返顺序保持；换一批更换种子与首屏顺序；390×844 下按钮可见、页面无横向溢出、无错误提示。未部署到用户运行服务。
- codestable：无 spec/epic 需同步。与本会话上一项 HLS 改动一并交付。已有 CSS 字节基线换行问题不在本次范围。
