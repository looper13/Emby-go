# 登录与媒体库访问权限

本功能采用管理员管理账号与授权、普通用户浏览媒体的模式。保留原管理员（用户 ID `1`），支持创建多个普通用户；媒体库权限、收藏、已看、播放次数与播放进度按用户隔离。当前不支持新建管理员或自定义角色。

## 控制台

首次运行通过初始化页面创建管理员，已有安装继续使用原账号。账号为 3-64 个字符；新建或修改的密码至少 9 个字符，UTF-8 编码不超过 72 字节。密码以 bcrypt 哈希保存，不在账号查询接口返回。

管理员登录后打开侧栏“用户管理”：

- 可创建普通用户、修改用户名、重置密码、启用/禁用和删除账号；原管理员不可禁用或删除。
- 新用户默认不允许访问任何媒体库。升级保留原管理员原有授权，不自动收紧已有访问范围。
- 取消“允许访问所有媒体库”后，勾选指定库并保存；不选择任何库表示不可浏览任何媒体。
- 账号与媒体库权限分开保存。恢复按钮放弃对应草稿；保存失败保留输入，切换用户或离开页面前确认未保存改动。
- 修改账号信息或禁用账号使该用户所有密码登录会话失效，不影响其他用户。管理员修改自身账号后也须重新登录。
- 删除用户同时清理其授权、登录令牌、收藏与播放记录，不删除媒体文件。

普通用户登录后进入媒体墙，保留动漫、收藏、媒体墙和“我的账号”入口；没有维护按钮、扫描任务轮询或管理页面权限。“我的账号”只展示可访问的媒体库，不允许自行授权。所有用户均可验证当前密码后修改自己的账号或密码，成功后须重新登录。顶栏“退出登录”只撤销当前会话；失败时保留登录状态并允许重试。

权限保存在 SQLite，刷新或重启后保留。删除媒体库会同时删除它的授权记录。选择所有媒体库后，新建媒体库自动可访问；指定库模式下必须手动授权新库。旧单账号授权只在首次迁移时导入，后续启动不会恢复已撤销的旧授权。

## Emby 接口

认证与退出参照 [Emby 用户认证](https://dev.emby.media/doc/restapi/User-Authentication.html)，访问范围参照 [Emby 内容访问](https://emby.media/support/articles/Content-Access.html)。`/Users`、`/Sessions` 等 Emby 接口支持裸路径、`/emby` 前缀及全小写路由；`/api/` 控制台接口使用表中的原路径。

| 接口 | 用途 |
| --- | --- |
| `POST /Users/AuthenticateByName` | 发送 `Username`、`Pw`，成功返回 `AccessToken` 和 `User` |
| `POST /Users/{id}/Authenticate` | 按真实用户 ID 登录，发送 `Pw` |
| `GET /Users/Me` | 查询当前账号和媒体库策略 |
| `POST /Sessions/Logout` | 撤销当前密码登录令牌 |
| `POST /Users/{id}/Policy` | 管理员保存目标用户的 `EnableAllFolders` 和 `EnabledFolders` |
| `GET /api/admin/users` | 管理员查询用户及供授权选择的全部媒体库 |
| `POST /api/admin/users` | 管理员用 `Username`、`Pw` 创建普通用户 |
| `PUT /api/admin/users/{id}` | 管理员提交 `Username`、`NewPassword`、`IsDisabled`；空密码保留原密码 |
| `DELETE /api/admin/users/{id}` | 管理员删除普通用户 |
| `GET /api/browse/libraries` | 返回当前用户可访问的启用媒体库，不提供磁盘路径 |
| `GET /api/admin/account` | 查询当前账号；管理员返回全部媒体库，普通用户只返回可访问库 |
| `PUT /api/admin/account` | 修改当前账号，发送 `Username`、`CurrentPassword`、`NewPassword`；空新密码仅修改用户名 |

后续请求使用 `X-Emby-Token`。同时接受现有 `X-MediaBrowser-Token`、Emby/MediaBrowser `Authorization` 与兼容查询参数。被撤销的登录令牌返回 401，不会因 Redis 里保留旧缓存而重新有效。

`User.Policy.EnableAllFolders=true` 表示所有启用库可访问；否则以 `EnabledFolders` 为授权清单。清单使用管理查询返回的媒体库外部 `Id`，不是影片 ID 或数据库内部库 ID。两字段须同时提交，空清单用 `[]`，不能用 `null`；无效或已删除的库返回 400，原权限不变。普通用户不能修改策略（403），也不能通过 URL 或 `UserId` 查询参数读写其他账号的媒体状态（404）。浏览和播放读取从登录令牌确定用户；收藏、已看等用户路径使用当前账号 ID。

浏览器登录同时建立 HttpOnly、SameSite=Strict 的会话 Cookie，HTTPS 下设置 Secure；它只用于 GET/HEAD 的同站资源请求。权限修改、退出等写请求仍须令牌，不接受仅 Cookie 的写入。

## 权限边界

媒体库限制覆盖影片、剧集/季/单集、混合库和动漫的浏览路径，以及搜索、最新、续播、合集、筛选元数据、人物、图片、详情、播放信息、流代理和播放记录写入。无权访问的资源返回 404；聚合列表在 SQL 计数和分页前过滤授权范围。

权限保存会使相关浏览缓存立即失效，包括已预热的合集名称缓存；用户相关缓存包含身份维度。图片使用私有缓存并要求重新验证；条件请求也先检查权限，不能以 304 绕过限制。字幕签名绑定签发用户，HLS 会话绑定创建用户，交付入口检查该用户是否存在、启用以及仍拥有媒体权限，不借用原管理员的浏览权限。媒体会话的停止与保活不能操作其他用户的会话。浏览器切换账号时清理媒体墙、播放器与管理任务状态，旧播放器不会向新账号上报进度。

动漫绑定的实际影片也必须属于授权目录库；只授权动漫在线库而未授权其绑定来源，不会获得该影片的播放权限。

管理员仍可进入媒体库配置、重新授权、扫描与维护页面；后台扫描和管理任务使用完整媒体索引，不因取消管理员自身浏览授权而停止。普通用户的维护请求返回 403；为兼容现有前端，少量 `/api/admin/` 下的浏览 GET 与自身账号接口继续对普通用户开放，但同样按当前用户过滤。

独立 API 密钥保持管理员级服务凭据性质，不是普通用户令牌，不因密码会话撤销而失效；不要分发给普通用户。当前未实现家长控制、内容分级、访问时间段、设备白名单、远程访问策略、登录页头像选择、Emby Connect 或完整会话管理面板。已发出的上游直拉 URL 无法撤回；重置密码不会单独撤销仍在有效期内的资源交付凭据，撤销库权限或禁用账号会阻止后续字幕/HLS 交付。
