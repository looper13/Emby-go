# 普通媒体详情的 JavDB 评论与清单

在目录媒体库的普通影片详情中，有已入库番号的影片会在演员区域下方显示“JavDB 评论与清单”。页面复用当前用户可访问的 AVdb-Only / JavDB 资料库连接；多个来源时可选择资料来源。电视剧单集和无番号影片不查询此资料。

当前界面结构：

```text
影片简介、剧照、演职人员
JavDB 评论与清单                            [重新匹配]
番号  [资料来源]                    [查看 JavDB 影片资料]
[评论] [相关清单]
作者 · 评分 · 日期 / 清单名称和影片数量
[展开完整评论] 或 [查看清单影片]
┌─封面 [本地可播放]─┐  ┌─封面 [无本地 STRM]─┐
│ 番号 / 影片标题   │  │ 番号 / 影片标题     │
│ [本库详情]        │  │ 点击封面、标题看资料│
└──────────────────┘  └────────────────────┘
[加载更多影片]
[上一页]                  当前页                  [下一页]
相似影片、文件信息和元数据
```

手机端来源选择、状态提示及分页信息换行排列，评论和清单仍在同一个区域中切换。评论默认加载，相关清单在第一次切换时加载；返回评论保留已读取内容。长评论可展开、收起，正文始终按纯文本显示。点开清单后显示全部上游影片的标题、番号和封面，不按本地匹配结果筛掉影片。海报右上角标记本地播放状态；点击封面或标题进入 JavDB 影片详情，可播放条目另有本库详情入口。390 像素手机显示两列，320 像素窄屏显示一列。

## 使用与状态

- 先在“媒体库”中添加 AVdb-Only / JavDB 来源；普通用户需要同时获得目录库与 JavDB 库的访问权限。没有可访问来源时显示添加或授权提示。
- 服务器使用影片已入库的完整番号搜索 JavDB，核对番号后取得影片 ID；不根据标题、文件名或搜索结果顺序猜测影片。未匹配、多个精确候选及上游失败分别提示。
- 匹配后可进入现有 JavDB 影片详情。相关清单展示名称及上游提供的清单数量，点击“查看清单影片”后完整展示清单影片。影片 ID、标题、番号和封面来自 JavDB，不用本库匹配条目代替清单本身。没有本地匹配的影片显示“无本地 STRM”；仅当清单本身没有影片时显示空态。
- 本库范围固定为当前详情影片的 `library_id`，即使当前用户获得其他目录库授权也不跨库匹配；匹配沿用现有完整番号规则，忽略 ASCII 大小写和分隔符，保留数字前导零、版本后缀。空番号、未就绪状态和电视剧单集不参与。原有 R18 详情查找跨库可播 STRM 的行为独立保留。
- “本地可播放”需本库番号匹配且实际 STRM 文件在库目录内可读取、包含有效 HTTP/HTTPS 播放地址；只有索引、文件缺失或内容无效时不会标为可播放。校验复用现有目录、多目录和分段规则，不请求视频源。多个本库版本分别提供详情入口；同一影片的多个 STRM 分段不重复生成本库条目。
- 封面通过现有同源图片代理按需读取，复用 2:3 海报、横向封套裁剪和“隐藏媒体图片”设置。缺失或失败的封面保留海报占位，标题和角标仍可查看；隐藏图片时不请求封面。蓝色角标表示当前本库有可播放 STRM，不代表网盘下载或跨库匹配结果。
- 评论与清单独立分页、独立重试。某页失败保留之前的内容，重试读取失败页。上游未提供总数时只显示当前页；没有 `has_next` 时用满页结果判断是否允许尝试下一页。
- 切换影片、来源或离开详情时取消旧请求并忽略迟到响应。每页响应包含当前番号、JavDB 影片 ID 和来源 ID；与页面匹配身份不一致时提示重新匹配，不展示该响应。
- AVdb 需要能访问 JavDB；若评论或清单加载失败，检查其 API 版本、连接以及服务端 JavDB 登录状态。AVdb 的 401 不会作为 Emby 登录失效返回。

## 接口与运行边界

内部接口均要求 Emby 登录，响应不允许浏览器缓存：

| 方法与路径 | 参数 | 用途 |
| --- | --- | --- |
| `GET /api/r18/items/{id}/match` | `library_id`，可选 `refresh=1` | 用本地影片番号匹配 JavDB |
| `GET /api/r18/items/{id}/reviews` | `library_id`、`page`、`limit`，可选 `refresh=1` | 读取匹配影片的评论 |
| `GET /api/r18/items/{id}/related-lists` | 同上 | 读取匹配影片的相关清单 |
| `GET /api/r18/items/{id}/related-lists/{list}/movies` | `library_id`、`page`、`related_page`，可选 `refresh=1` | 返回全部清单影片、代理封面及本库可播放状态 |

评论与清单头列表每页读取 15 条。服务器允许页码 1–9999、每页 1–50 条；番号解析最多搜索四页、每页 50 条，找到精确候选后停止，遇到同页多个不同影片 ID 的精确候选时拒绝选择。

选定清单后，每次读取一个上游影片页、每页 50 条，再通过一次 SQL 查询匹配当前目录库并校验实际 STRM。页面用“加载更多影片”继续下一页，累计结果按 JavDB 影片 ID 去重；同番号的不同 JavDB 影片仍保留各自卡片。页面显示已加载影片数和其中本地可播放的影片数，不伪造清单总数。`related_page` 指定清单头所在页，服务端重新核验该清单确实关联当前 JavDB 影片。

请求共享 20 秒预算，本地索引及 STRM 校验在剩余预算内最多使用 5 秒。搜索、评论、清单及其上游影片页复用现有有容量限制的短期浏览缓存；失败不缓存，重试可绕过缓存。本地可播放状态不缓存，每次重新查询当前索引和权限并读取实际 STRM，新增、移除、番号或文件内容变更在下一次读取中生效。

每次请求在访问缓存或上游前核验两个媒体库的当前权限，并重新读取本地番号。浏览器传入的其他番号、上游影片 ID 或本库 ID 不作为匹配范围依据。上游仅收到配置的 AVdb API Key，不接收浏览器 Cookie 或 Emby Token；影片仅返回 JavDB ID、番号、标题、同源封面地址和本地播放标记，附属本库条目只返回本地 ID、番号和标题，不暴露私人路径或 STRM 播放地址。

上游调用为 `GET /api/v1/javdb/search`、`GET /api/v1/javdb/movies/{movie_id}/reviews`、`GET /api/v1/javdb/lists/related`，清单影片使用 `GET /api/v1/javdb/movies/tags?list_id=...`。字段和分页映射对照了 2026-11-18 发布前端的实际读取方式，接口目录见 [AVdb-Only API 文档](https://github.com/li-peifeng/AVdb-Only/wiki/API%E6%8E%A5%E5%8F%A3)。本功能只读取资料，不写入 NFO 或 JavDB，也不提交下载、评论、评分或清单收藏。
