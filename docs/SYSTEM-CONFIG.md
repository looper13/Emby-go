# 实例配置页面

管理员登录后，打开侧栏“设置”。页面读取启动时 `-c` 指定的 YAML 文件，点击“保存配置”才会写入；“恢复已保存设置”撤销当前草稿，“重新加载文件”读取外部改动。MetaTube、GFriends 和翻译选项继续在“刮削配置”中管理。

页面结构（已通过桌面和移动端浏览器验收）：

```text
设置
┌ 实例配置 ───────────────────────────┐
│ 配置文件路径 / 待重启项目 / 监听异常   │
├ 服务基础：名称、端口、调试、只读 ID    │
├ 媒体库监控：启用、实时 / 兼容模式     │
├ 存储：数据库、演员资料目录、当前路径   │
├ Redis：地址、数据库、密码、明确清除    │
├ 媒体探测：ffprobe、超时、并发         │
├ 字幕音轨：FFmpeg 开关、路径、并发、缓存│
├ 备用域名：名称 + 地址 [添加 / 删除]   │
│ [保存] [恢复已保存] [重新加载] 未保存  │
└─────────────────────────────────────┘
保存结果 / 错误（失败保留草稿）
当前运行状态：监听地址、存储、Redis、缓存统计
```

桌面字段两列，移动端单列；每组显示生效时机。保存期间锁定表单，避免重复提交；离开未保存页面或重新加载文件时提示丢弃确认。配置文件不可读时显示加载错误，可重试；无来源文件时禁用保存。

| 配置 | 保存后的行为 |
| --- | --- |
| 服务名称、备用域名 | 后续 Emby API 请求立即使用新值 |
| 监控开关、实时/兼容模式 | 停止旧监听并按新配置启动，失败显示警告并保留至下一次重建 |
| ffprobe 路径 | 下次任务使用，任务开始前检查可执行文件 |
| 探测超时 | 后续发起的单条 ffprobe 调用使用新值；已发出的调用保持原超时 |
| 探测并发 | 下一次批量任务使用，当前 worker 数不改变 |
| FFmpeg 开关、路径、播放并发、缓存上限 | 后续字幕提取/播放会话使用；已启动的会话保持原参数 |
| 端口、调试、数据库、演员目录、Redis | 保存文件，显示待重启项目；当前进程继续使用原值 |

页面不会自动重启服务。更换数据库或演员目录不会复制旧数据；重启前请完成必要迁移。Redis 连接在重启时校验；ffprobe 在任务启动时校验。保存成功表示格式合法并已落盘，不代表新的外部资源一定可达。直接编辑 YAML 文件不会自动触发热更新。

配置文件保留注释与未知字段（YAML 格式/缩进可能规范化）；同目录临时文件写入、刷新、关闭后替换。程序用户需要配置文件及父目录的读写权限；容器建议挂载配置目录，单文件绑定挂载可能无法替换。Linux systemd 部署见 [部署说明](../deploy/README.md)。

Redis 密码不回传；输入留空保持原值，清空必须勾选“清除已保存的 Redis 密码”。实例 ID 只读。多个页面或外部程序修改文件后，旧版本保存返回 409，保留草稿，需重新加载后重试。

接口：鉴权后的 `GET /api/admin/config` 返回 `config_path`、`writable`、`revision`、`config`（文件值）、`effective`（运行值）、`restart_fields`、`warnings`；`PUT /api/admin/config` 接受 `{revision, config: {...仅修改字段}}`。`GET /api/admin/settings` 继续提供运行状态和缓存统计。YAML 相对数据库路径基于进程工作目录，演员相对目录基于数据库目录；页面同时展示实际解析路径。
