# 任务分解

| 阶段/任务 | 优先级/规模 | 依赖 | 验收 |
|---|---|---|---|
| P1.1 Archive 下载、校验、解析 | P0/L | 无 | 官方 manifest；有界下载；合成归档解析 |
| P1.2 独立目录存储与快照发布 | P0/L | P1.1 | 未完成导入不可见；失败保留旧目录 |
| P1.3 主体入口和当前关系 | P0/L | P1.2 | 无蜜柑也可浏览；正常更新保持绑定和 ID，不做旧版本迁移 |
| P1.4 Web 目录与同步状态 | P0/M | P1.3 | 检索、详情、导入进度与错误可见 |
| P1.5 一键下载/更新入口 | P0/M | P1.4 | 主目录与设置页可启动后台下载；阶段进度、取消、重试、无新版本和刷新页面可追踪 |
| P2.1 独立图片索引和文件存储 | P1/L | P1.2 | 重启可用；无图片 BLOB；失败不阻塞目录 |
| P2.2 角色/人物关系和图片 | P1/M | P2.1 | 身份区分、正确关联、缺图状态 |
| P2.3 按需及批量图片任务 | P1/L | P2.2 | 有界任务、取消/重试/进度 |
| P3.1 TMDB 设置与客户端 | P1/M | P2.1 | 可选、显式保存、凭据脱敏 |
| P3.2 主体/章节映射 | P1/L | P3.1 | 人工确认、乐观锁、特殊集数 |
| P3.3 章节剧照获取与展示 | P1/M | P3.2 | 多图/缺图/错误，不冒充封面 |
| P4.1 定向与全量回归 | P0/M | P1-P3 | Go、类型检查、前端单测/构建 |
| P4.2 桌面/移动端主路径 | P0/M | P4.1 | 隔离服务截图与交互测试 |
| P4.3 文档和交付边界 | P0/S | P4.2 | 备份/恢复/来源说明，实机未验证明确 |
