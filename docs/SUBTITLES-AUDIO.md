# 字幕与音轨

本项目仍以 HTTP(S) `.strm` 为媒体入口。本地字幕/外挂音频放在 `.strm` 的同目录，按完整基础文件名匹配：

```text
Movie.strm
Movie.zh-CN.default.srt
Movie.zh-TW.ass
Movie.en.forced.srt
Movie.eng.Commentary.flac
```

支持字幕文件 SRT、VTT、ASS、SSA、SMI/SAMI、SUP 的发现。网页直接支持 SRT/VTT，ASS/SSA 转 WebVTT 显示正文，复杂样式与特效不保留；SMI/SUP 供支持相应格式的原生客户端使用。IDX/SUB 成对图形字幕、PGS/VobSub 网页烧录不在当前范围。

语言支持 ISO 代码、`zh-CN/zh-TW/zh-Hans/zh-Hant` 和常见 `chs/cht`；`.default` 表示默认，`.forced/.foreign` 表示强制，`.sdh/.cc/.hi` 表示听障。同目录同名匹配，`Movie2.srt` 不会挂到 `Movie.strm`。CD 分段分别关联自己的文件名。无用户选择记录时字幕优先使用显式默认的外挂轨，再使用显式默认的内封轨，否则关闭；音轨优先容器默认轨，再取首条内封音轨。

**发现时机**：仅单条 Emby 条目详情、管理端单条详情和 `PlaybackInfo` 请求读取该条目的同目录文件名。影片、电视剧、动漫、推荐、续播等列表（包括显式请求 `Fields=MediaSources`）以及普通媒体库扫描均不调用字幕发现。发现不联网、不执行 ffprobe、不写 NFO/数据库。新增、删除、修改字幕在下一次详情/播放信息请求生效；正在播放时可关闭后重新打开刷新清单。已有 `mediainfo.json` 在详情/播放时可本地还原完整多音轨，源地址变更后不沿用旧索引。

全轨探测由现有“探测媒体信息”动作执行。探测版本为 2，保留每条音轨、字幕的真实容器索引及音轨标题；旧单音轨 NFO 可正常读取。已有原始探测缓存优先本地重新映射，缺少缓存时才重新联网探测。外挂文件事实来自目录，不写回 NFO。

对外 `MediaStreams[i].Index` 始终等于数组下标；真实容器索引放在 `ContainerIndex`，仅供 FFmpeg 映射。外挂音频和字幕按顺序追加，详情、播放信息和取流共用同一份轨道排序。文件清单或媒体信息变化会更新 `TrackRevision`，网页不再复用可能错位的旧选择。

网页的“音轨”和“字幕”选择位于影片/单集详情页播放区，字幕可关闭；动漫详情中的每个可播放条目通过播放按钮旁的设置图标展开同一组控件，未展开不逐集加载播放信息。选择只属于当前详情，点击播放时传入；媒体墙、总览等直接播放入口始终使用源的默认轨道，不读取上一次详情的选择。播放时重新核对媒体源 ID 与 `TrackRevision`，失效选择回退默认并提示。播放器内不再放选轨菜单，仅保留播放控制、处理状态/错误和重封装位置滑块。

HLS/支持原生选轨的浏览器可通过轨道 API 应用详情里已知的内封轨道；若尚未探测出完整流信息，应先探测媒体信息。普通 MP4/MKV 的其他音轨及外挂音频需要启用 FFmpeg。界面区分需启用 FFmpeg、需重新探测和需原生客户端的轨道。选择非默认音轨时先准备重封装流，再打开播放器，避免先播放默认音轨；续播位置保留。

## 外部播放器

详情播放区的“外部播放”菜单提供 PotPlayer、VLC、MPV。链接分别为 `potplayer://HTTP_URL`、`vlc://HTTP_URL`、`mpv://HTTP_URL`，交给用户本机已注册的协议处理器；本次不会安装客户端、改写注册表或启动后台常驻助手。播放器可执行文件存在不代表协议已注册，浏览器也不能可靠判断应用是否成功打开。

外部入口打开原始 HTTP(S) 媒体，使用原生客户端自己的默认音轨/字幕；网页所选轨道、服务器上的外挂字幕、网页续播位置及进度回传不通过这三个基础 URL 协议传递。`PlaybackInfo.MediaSources[].ExternalStreamUrl` 与鉴权后 `/stream` 的跳转目标相同，不附加本服务的账户令牌或 Cookie，不进入共享详情/列表缓存。客户端必须能访问该源地址；源站签名过期后重新打开详情刷新链接。

MPV 使用新版原生 `mpv://` 网络 URL 格式，不使用旧 `mpv://play/base64` 形式。第三方 mpv-handler 自 0.4 起使用独立的 `mpv-handler://`，不是本菜单的协议。协议处理器参考：`https://mpv.io/manual/master/`、`https://github.com/akiirui/mpv-handler`、`https://github.com/stefansundin/vlc-protocol`。

## 播放处理

可选配置（设置页可保存，无需重启）：

```yaml
ffmpeg_enabled: false
ffmpeg_path: ""          # 默认从 PATH 查找
playback_concurrency: 2   # 1–4，字幕提取与音轨处理共用
playback_cache_mb: 2048   # 单会话临时磁盘上限，64–65536 MiB
```

本地外挂字幕不依赖 FFmpeg。启用后内封文本字幕按需提取，结果按源地址/索引/格式缓存 10 分钟，最多 8 份，每份最多 16 MiB。提取超时使用已有 `probe_timeout_seconds`。字幕文件支持 UTF-8、带 BOM 的 UTF-16、GB18030；实际读取时检查目录归属、符号链接、普通文件类型及大小。

音轨处理复制视频，容器内 AAC 优先复制，其他音频转为 AAC 双声道；外挂 MKA/FLAC/AAC/AC3/EAC3/DTS/M4A/MP3/OGG/OPUS/WAV 支持按名称发现并按需合流。视频编码必须能被目标浏览器解码；本功能不转换视频编码。FFmpeg 退出时立即归还处理并发槽，已生成的 HLS 分片仍由播放会话保留供播放器读完。关闭/停止、失败或服务正常退出时清理临时文件；无请求超过 90 秒回收，最长 4 小时，达到配置的缓存上限也会停止。网页打开期间发送会话心跳；长片和高码率源可按磁盘容量调大缓存上限。

重封装播放的完整影片定位使用播放器内“播放位置”滑块：按目标位置重新开始处理，字幕时间相应平移。Artplayer 原有进度条仅覆盖当前会话已生成的片段。处理后的视频流会经过本服务，占用服务端带宽和临时磁盘；普通直连/HLS 源继续沿用原播放路径。

Emby 接口包含详情/播放信息的 `MediaStreams`、默认索引和字幕 `DeliveryUrl`。字幕地址 `/Videos/{Id}/{MediaSourceId}/Subtitles/{Index}/Stream.{Format}` 可使用正常账户鉴权，也可以直接使用返回地址中的资源签名，无需播放器附加请求头。签名有效期 4 小时，限定条目、媒体源、轨道和清单版本；文件变化或服务重启后需重新获取详情/播放信息。共享详情缓存不含账户令牌。原始 ASS/SSA/SRT 可供原生客户端读取，网页请求 VTT 转换。

字幕 GET/HEAD 同时支持 `.../Subtitles/{Index}/{StartPositionTicks}/Stream.{Format}` 变体及 `/emby`、小写兼容路由；ticks 必须非负。当前均交付完整字幕并保留源时间戳，网页在重封装跳转后自行平移 VTT，不按该路由参数截断字幕。

启用 FFmpeg 且索引可靠时，仅在请求显式选择非默认音轨或外挂音轨后，`PlaybackInfo` 才提供音轨处理的 `TranscodingUrl`（`master.m3u8`）；未选轨及显式选择默认轨仍声明 `SupportsTranscoding=false`。选中外挂音频时关闭该媒体源的直接播放能力。此地址仅用于音轨处理，不提供视频转码或字幕烧录。详情中的内封音轨与外挂音轨同时展示；不支持网页转换的字幕（如 SMI/SUP）不会自动选中。

处理生成的子清单、初始化片段和分片以随机 128 位会话 ID 限定访问；账户令牌不会写入清单或转发给远程片源。内封字幕原生播放和 HLS 轨道切换能力仍取决于具体客户端；服务端契约测试和本机浏览器验证不代表所有 Emby 客户端已实测。
