# JavDB 在线资料库（AVdb-Only API）

作为独立的 `avdb_javdb` 媒体库来源，通过 AVdb-Only API 按需获取 JavDB 影片、在线磁力与 AVdb 本地资源库磁力，不再直接连接 PostgreSQL。不生成 NFO/STRM 文件，也不将全库影片导入本地 SQLite。按番号关联本项目目录库的已有 STRM，优先复用目录库播放；没有本地版本时可使用 115 磁力流程。资料浏览接口保持 `/api/r18`，115 播放仍使用 `r18-` 路径，本地 STRM 使用普通影片/分段播放路径。

接口契约见 [AVdb-Only API 文档](https://github.com/li-peifeng/AVdb-Only/wiki/API%E6%8E%A5%E5%8F%A3)。浏览使用 `GET /api/v1/javdb/movies/tags`，搜索使用 `GET /api/v1/javdb/search`，详情使用 `GET /api/v1/javdb/movies/{movie_id}`，磁力使用该影片的 `/magnets` 接口。

## 添加与浏览

1. 更新并启动包含新 Vue 页面及后端的版本。
2. 管理员进入“媒体库”，展开“添加 AVdb-Only / JavDB 资料库”，填写名称、AVdb 基础地址及 AVdb 访问令牌（API Key）。地址可包含反向代理路径前缀，不接受 URL 凭据、查询参数或片段。
3. 点击连接并添加。服务通过只读 GET 验证 JavDB 列表接口，成功后保存配置；失败时保留表单供修正。
4. 点击该库的“浏览”，或进入侧栏“JavDB 资料库”。多个来源可在页面选择切换。普通用户须由管理员在“用户管理”授权媒体库后访问。
5. 修改连接时点击该库的“连接配置”。API Key 不回显；编辑时留空保留已保存 Key，保存成功后清空输入框。

列表展示封面、标题、番号、发行日期、时长、评分及上游磁力数量；匹配到本项目可播放 STRM 的影片标记“本地 STRM”。支持以下操作：

- 统一关键词搜索，不再区分重复的番号/标题搜索模式；关键词交给上游模糊匹配，不宣称精确番号搜索。
- 分类可选全部、有码、无码、欧美或 FC2；资源可选全部、有磁力、中文字幕或可在线播放。默认只看有磁力影片。“可在线播放”只是 JavDB 上游筛选，不表示本服务已绑定播放文件。
- 无关键词时可按发行日期、评分、热度、想看人数或看过人数排序，选择正序/倒序及单一年份；默认发行日期倒序。
- 搜索时按上游相关度排序，不支持年份筛选或发行排序。网页隐藏不适用的控件，接口拒绝不支持的组合，不用单页本地排序冒充全局排序。
- 明确显示当前页，支持上一页、下一页及输入页码跳转，范围为 `1..9999`；每页可选 24、40、50 条，默认 24 条。更换关键词、分类、资源、排序、年份或每页条数均回到第一页。
- 详情返回恢复页码、筛选、滚动位置及所选卡片；超时或失败保留当前条件，可以重试。

上游未提供全库总数，网页显示当前页和本页数量，不伪造总数或最后一页。响应只有 `items`、`page`、`page_size`、`has_more`、`has_previous` 和媒体库信息，不再提供旧游标和估算统计字段。数据按需读取，不预导入或全量同步。

## 图片尺寸

- 列表与详情封面统一使用与媒体墙相同的 `2:3` 海报框，等比填充、不拉伸。横向完整 DVD 封套展示右侧正面，竖版封面居中；缺图或隐藏图片时仍保留相同尺寸的占位。
- 网页封面使用 `/images/poster`，服务器先裁海报再等比缩小，默认最大 `320×480`、WebP 质量 82，不放大小图；像素取整可能使实际宽度略小于 320。原有 `/images/cover` 保留完整未裁封套，便于查看原图。
- 列表复用媒体墙的小/中/大卡片设置、网格宽度与间距。尺寸偏好共用并保存在浏览器中；窄屏按可用宽度自动减少列数，不强制压成两列。
- 详情封面宽度与普通影片详情对齐：桌面 156 像素，720 像素及以下为 120 像素，不随右侧长标题/资料区拉高。
- 剧照框统一为 `16:9`，等比完整展示，不再使用固定像素高度；查看原图仍通过同源代理获取未裁剪图片。

## 详情与磁力

进入详情后先加载影片资料与本地 STRM 版本，再单独读取该 JavDB ID 的磁力。分别读取 `online_magnets`（JavDB 在线）和 `library_magnets`（AVdb 本地资源库），保留来源标签；不使用合并字段 `magnets`。任一专用数组存在即可读取，空数组表示该来源暂无资源；两个数组都缺失或为 null 时明确报错，不静默回退旧来源。

- 展示影片封面、时长（分钟）、原始评分、完整剧照（最多 100 张）以及磁力来源、标题、日期、大小和标签；缺失评分/时长不伪造数值。
- 排除无效磁力或显式番号不匹配的候选，按规范化 BTIH/BTMH 去重；重复磁力合并来源与标签。资源 ID 使用磁力哈希，不使用不稳定数组下标或本地 article ID。
- 每次展示最多 50 条，可继续加载，资源偏移上限为 10000；资源归属查询重新读取当前影片的两个专用磁力数组，不信任浏览器传入的替代磁力。
- 可复制磁力；来源页面只在上游提供经校验的 HTTP(S) 地址时展示，不启动磁力协议处理程序。
- `size_bytes` 优先；`size` 按 MB 换算，缺失时显示大小未知。资源可用性未经下载验证。
- 仅包含 BTv2/BTMH 的磁力仍可展示和复制，但现有 115 离线流程只接受 BTIH，不将这类磁力列为可播放版本。
- 资源请求失败不影响已加载的影片详情，可以单独重试。封面和剧照遵循已有“隐藏媒体图片”设置。

## 已有本地 STRM 优先播放

AVdb 的 `library_magnets` 是本地磁力资源库，**不等于本项目已存在 STRM**。直接播放依据本项目 SQLite 中已经扫描入库的目录影片，不读取 API 提供的磁盘路径、不调用 AVdb 外部 Emby 播放接口。

- 列表按本页番号批量匹配；忽略大小写、空格与 `-`、`_`、`.` 分隔差异，保留前导零和版本后缀，不从标题或文件名猜测番号。只匹配已启用、当前用户可访问的目录库，以及已入库的非电视影片。
- 详情展示同番号的多个本地版本及有效 CD 分段，默认选第一个有效版本。目录内的真实普通 `.strm` 文件才可用，文件最多 64 KiB，首行必须是无 URL 用户凭据的有效 HTTP(S) 地址；缺失、损坏、越界路径和越界符号链接不算本地版本。
- 点击“播放本地 STRM”先通过 `GET /api/r18/libraries/:lib/videos/:video/local-playback?source_id=...` 复查影片归属、文件和授权，再使用普通 `/Videos/{本地影片或分段ID}/stream`、`/proxy` 播放。保留目录库的代理开关、Range、HLS、音轨和进度；网页响应不暴露完整磁盘路径或 STRM 原始 URL。
- 有本地版本时，页面不读取 115 状态，不提交、预检或轮询 115 任务。只有手动点击“使用 115 磁力流程”才启用下载入口；本地文件失效或播放器报错不会自动添加下载任务。
- 本地发现与播放复查同时要求 JavDB 资料库和目录库授权；普通流继续遵循现有目录库权限与原有匿名兼容边界，不新增匿名 R18 播放入口。文件、番号或权限变化后每次重新核验，不以旧详情缓存放行本地源。
- STRM 已在磁盘但还未被目录库索引时，先添加相应目录库并完成正常扫描。新增或移动文件/番号需要索引刷新；已入库 STRM 的内容修复无需重新扫描。

## 图片代理

列表封面、详情剧照及“查看原图”链接统一使用本服务的同源图片代理，浏览器不直接访问 API 返回的源站 URL。服务器仅按已授权条目的图片类型/序号读取源图，不接受任意 URL 代理；剧照索引为规范十进制 `0..99`，不存在的索引返回 404。

- 图片请求接受登录会话 Cookie，并在缓存命中或 304 前重新检查用户与媒体库权限；撤销授权后不能继续通过代理获取图片。
- 只代理 HTTP(S) 公网图片；每次请求及重定向检查目标地址，直连固定已校验 IP，拒绝内网、回环、链路本地等地址。不转发浏览器 Cookie、Emby Token、Authorization 或 AVdb API Key。
- 最多 4 路上游图片请求，与刮削预览共享限流；HTTP 超时 15 秒，单张上限 8 MiB。只返回识别为 JPEG/PNG/GIF/WebP/AVIF 的内容，不返回 HTML/SVG。
- 封面按需使用两级缓存：独立热内存最多 256 项、每项最多 128 KiB（图片数据约 32 MiB 上限），磁盘最多 512 MiB / 10,000 个文件，原图和各尺寸海报合计受限。成功封面有效期 24 小时，重启可复用磁盘文件；缓存过期、损坏或被淘汰后再读取源站，不预下载整个资料库。
- 网页与 Emby 默认 Primary 共用同一海报缓存；请求先检查成品海报缓存，不先读取/下载原图。新尺寸复用已缓存原图，同一封面并发请求合并下载；派生海报沿用原图的到期时间，不因另生成一个尺寸延长旧内容的有效期。
- 封面缓存键包含媒体库 ID/连接修订、条目 ID、源图 URL、处理算法版本、尺寸及质量。源图 URL 改变后使用新缓存；同一 URL 的内容更新可能要等到 24 小时到期才显示。条目源图片 URL 元信息仍缓存 1 分钟。
- 磁盘目录为本地 SQLite 所在目录的 `.work-cache/r18-covers/<实例命名空间>/`，文件名使用哈希，不保存源 URL 或数据库凭据；通过临时文件写入后改名，校验完整性并按到期时间/LRU 清理，仅管理自己的缓存文件。此目录不是静态公开目录，仍须限制所在目录的访问权限。目录不可写或磁盘缓存故障时记录警告并退回有界内存缓存，不中断正常图片响应。
- 剧照只在进入详情后按需懒加载，不预取、不加入封面磁盘缓存；小于等于 512 KiB 的成功剧照仍复用现有进程内缓存 10 分钟。浏览器使用私有缓存及 ETag 重验证，失败响应不缓存；所有缓存命中、HEAD 与 304 前仍重新检查授权。
- 服务器需要能够访问源图片站点；如服务器出网需要代理，可在服务进程环境中设置 `HTTP_PROXY` / `HTTPS_PROXY`。这与浏览器到本服务的图片代理、媒体库的播放代理开关相互独立。

## 权限与运行边界

- AVdb 请求仅使用 GET；API Key 只放在后端 `X-API-Key` Header，不放入 URL，不跟随 API 重定向。请求超时 15 秒、业务上下文上限 20 秒，JSON 响应上限 8 MiB；上游错误正文不直接回显。
- 保存连接和查看连接配置只允许管理员。普通用户的媒体库授权在访问 API 之前检查；管理接口只返回 `has_api_key`，不返回 Key。
- API Key 保存在本地 SQLite 的私有 `r18_api_connections` 表中，**未加密**。限制数据库、备份和所在目录的访问权限，使用 HTTPS 访问管理端与跨不可信网络的 API；仅可信内网可考虑 HTTP。
- 删除媒体库只删除本地配置与授权，不调用 AVdb 删除接口。该来源不参与目录扫描、监听、查重或播放代理配置。
- 本次不接入 AVdb 订阅、下载、账号登录或正片 `/play` 接口。JavDB 会话由 AVdb 服务端管理；浏览器无需 JavDB 密码或会话 Token。
- 升级前备份本地 SQLite；启动时旧 `postgres_r18` 媒体库映射为 `avdb_javdb` 并增加修订，保留 ID、影片、收藏、授权、自定义索引/触发器及离线历史。旧 PostgreSQL 连接表保留但不读取；旧库必须在“连接配置”填写 AVdb 地址与 Key 后才能浏览。新 JavDB ID 与旧内容 ID 不同，旧离线绑定不会自动错配；选择同一磁力可按原任务规则复用尚有效的任务。

## Emby / Yamby 只读浏览

R18 来源现在进入 Emby 媒体库枚举；普通用户仍须授权该库。根路径与 `/emby` 前缀、大小写路由及常见查询参数复用已有兼容注册。

- `GET /Users/{uid}/Views`、`/Library/MediaFolders`、`/Library/VirtualFolders` 及其 `/Query` 变体可列出 R18；媒体库仍使用原外部 ID，配置列表没有本地目录、源库连接或密码。
- `GET /Users/{uid}/Items`、`/Items` 带该库 `ParentId` 可浏览，支持 `StartIndex`/`Limit`、关键词和无搜索时单一年份筛选。默认有磁力影片、发行日期倒序；`PremiereDate`/`ProductionYear`/`DateCreated` 映射上游发行排序，`CommunityRating` 映射评分排序。搜索默认 `Relevance`，显式请求发行日期等搜索不支持的排序返回 400；`AppliedSortBy` 标明实际应用的排序。名称范围、多个年份或全局标题/内容 ID 排序未获上游支持，明确返回 400，不以单页本地筛选冒充全局结果。`Latest` 获取最新发行列表，不表示真实入库时间。
- API 来源不请求全库计数。`TotalRecordCount` 为当前偏移加返回条数的分页下界（有下一页时加 1），并返回 `TotalRecordCountIsEstimated=true`、`TotalRecordCountIsKnown=false`；仅用于客户端翻页，不是全库精确数量。单次最多返回 1000 条，上游每页最多 50 条；查询/超时失败返回可重试的 502。
- 影片 ID 为 `r18-{libraryID}-{复合条目ID}`，条目 ID 包装 `(JavDB movie_id, "javdb")`；从列表取得的 ID 可用于详情及按 ID 查询，不沿用旧 PostgreSQL 影片身份。
- 有已授权且有效的本地 STRM 时，返回普通目录影片/分段的 `MediaSources`，`PlaybackInfo` 默认只提供本地版本，不访问 115；本地来源保留普通 `mediasource_<影片或分段ID>`，不包装成 115 来源。显式选择 `115-*` 或没有本地源时才读取现有 115 就绪绑定。
- 没有本地 STRM 或就绪 115 文件时保持不可播放的虚拟 Movie：`IsPlaceHolder=true`、`PlayAccess=None`、空 `MediaSources`/`MediaStreams`，`PlaybackInfo` 返回 `NoCompatibleStream`。115 文件使用本服务签名播放入口，不伪造未知编码、时长或入库时间。
- `/Items/{id}/Images` 提供图片标签；`/Images/Primary`、`Thumb` 及 `Backdrop/{index}` 经同一服务器代理返回，支持 GET/HEAD、ETag/304 和尺寸参数。Primary 在服务器裁成 2:3，横向封套取右侧正面，未指定尺寸时最大 `320×480`；其它图不裁剪。封面原图/派生尺寸使用上述两级缓存，剧照保留轻量内存缓存；转换复用既有像素上限及 CPU 并发限制，不支持解码的格式回退源图。
- R18 图片须携带有效访问令牌（Header、api_key 等）或登录 Cookie；原有本地媒体的匿名图片兼容不变。所有 R18 图片缓存与 304 前重新检查授权，源站不收到客户端凭据。未建模的 Logo/Banner/Art 返回 404；已存在条目的相关推荐、合集、附加分段、特殊内容及时间轴预览返回空结果。

## 115 离线下载与播放

1. 管理员进入“设置 / 115 连接”，只填写 Cookie（必须含 UID、CID、SEID，可含 KID），点击“验证并保存”。无需 Access/Refresh Token 或手填目录 ID；服务自动创建或复用网盘根目录的 `缓存-24h自动删除`。输入留空保留既有 Cookie，接口不回显。旧 OAuth 配置需重新填写 Cookie；当前只支持同一共享账号更新凭证，不支持切换账号。
2. 没有本地 STRM，或已手动切换到 115 磁力流程时，在 R18 详情选择磁力版本点击“播放”，或在当前磁力列表点击“播放此版本”，自动提交/复用任务、等待并打开播放器；服务端重新核验当前 JavDB 影片的在线/本地资源库磁力归属，不使用浏览器传来的替代磁力。也可在手动磁力框“添加并播放”BTIH 磁力（十六进制或 Base32）。提交仅管理员；普通授权用户只能播放就绪版本。不同 BTIH 对应不同版本，重复 BTIH 合并展示。
3. 每个任务在统一缓存目录下创建 `emby-go-{任务ID}` 子目录，再提交离线下载。后台轮询 115，页面只查询本地任务，等待自动播放时每 1 秒读取一次，其它任务状态每 5 秒读取。重复磁力复用同账号任务；提交超时或程序重启先对账，不盲目再次提交。下载完成在同一轮确认缓存归属并扫描结果，复用本轮刚获取的文件信息，不跨播放缓存文件存在性。单个合格视频自动绑定，一键播放时多个候选推荐最大视频，保留手动“正片文件 / 设为默认播放源”。样片、图片和压缩包不作为视频。相同磁力已在其它网盘目录下载且文件仍存在时，不使用或删除外部文件。
