# 风险与证据

| 风险 | 实现约束 | 验证 |
|---|---|---|
| 坏包/取消/断电导致目录丢失 | 长度与 SHA256 校验、受限 ZIP、流式导入、完整校验后发布新版本；旧库保留 | 合成包、坏包、取消、重开测试 |
| 全量写入阻塞播放 | 目录独立 SQLite，不在业务库整体重建 | 旧目录并发读取、绑定回归 |
| 本地 ID 或观看状态漂移 | 以 Bangumi 外部 ID upsert，保留已有本地 ID、映射和 userdata | 重复刷新/迁移/绑定测试 |
| 图片混用、内存膨胀或 SSRF | 类型与来源隔离、文件落盘、有界请求/尺寸/并发、可信域名与公网解析 | 图片类型、坏图、重启、URL 拒绝测试 |
| 剧照对应错误 | 显式主体和章节 TMDB 映射；不猜合集或跨季编号 | 映射冲突、特殊集数、无图片测试 |
| 外部权限/来源边界 | 凭据不回传浏览器，来源记录独立，数据不打包进二进制 | 脱敏 API/发布检查 |

Archive 不是 API JSON：platform 使用官方常量映射，infobox 保留原文，章节 description 转换为 summary。快照不是完整实时数据；日期未知保留未知。首播季度与蜜柑放送季度明确区分。

验证在临时数据库/目录进行。不运行会清理本机 Redis DB15 的既有 TestRedisBehavior；全量 Go 回归使用 frontend 的 test:go-regression。
